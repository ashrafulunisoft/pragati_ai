### ৩.১ যা ইতিমধ্যে ঠিক/তৈরি করা আছে (2026-09-06 এর অভ্যন্তরীণ রিভিউ সাইকেল থেকে)

| ফিক্স | কী করা হয়েছে | টেস্ট |
|---|---|---|
| **P1 — Decision Fusion (F1–F5)** | `S = max(S_rule, S_AI)` — AI স্কোর নামাতে পারে না, শুধু বাড়াতে পারে; AI-MALICIOUS + score≥50 এখন ব্লক করে | `McpDecisionFusionTest` (9) |
| **P2 — Tiered fallback** | AI down: ≥80 fail-closed, 50–79 N-strike throttle (৩য় স্ট্রাইকে 429+900s block), <50 monitored allow; `timeout(10)+retry(1)`; Redis down → cache fallback | `McpFailoverPolicyTest` (6) |
| **P3 — আসল MCP** | JSON-RPC 2.0 / Streamable HTTP / spec `2025-06-18`; MCP server `/api/mcp` (Bearer token), tool `analyze_login_risk`, client + handshake; `MCP_DRIVER=direct\|mcp` ablation সুইচ | `McpProtocolTest` (12) |
| **P4 — Prompt injection ডিফেন্স** | L1 sanitizer → L2 malformed skip → L3 fenced prompt → L4 rule-floor | `McpPromptInjectionTest` (10) |
| **P5 — Evaluation harness** | `php artisan security:evaluate --ai=off\|honest\|adversarial\|live --seed=N`; ৭টি সিনারিও, ground truth generator থেকে | — |
| **P6 — Pseudonymization** | email → HMAC hash, IP → /24-/64 prefix + HMAC; raw PII বাইরে যায় না | `McpPrivacyPseudonymizationTest` (7) |
| **M7 — Atomic Lua** | INCR+EXPIRE এক Lua-তে, TTL শুধু প্রথম increment-এ → আসল fixed 15-min window | `McpAtomicRedisTest` (5) |
| **M8 — Configurable thresholds** | সব threshold/band/weight env-driven (`LOGIN_ATTEMPT_THRESHOLD_IP` ইত্যাদি) | `McpConfigurableThresholdsTest` (6) |
| **M9 — NAT mitigation** | ≥3 distinct successful account দেখলে email-scoped block (পুরো IP নয়) | `McpNatMitigationTest` (5) |
| **M10 — Challenge enforcement** | captcha/OTP → **HTTP 428** + single-use token; solve করলে pass | `McpChallengeEnforcementTest` (10) |
